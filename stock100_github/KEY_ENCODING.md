# 访问验证与密钥编码

## 使用顺序

1. 双击 `启动工具.cmd`，或在Streamlit部署时选择 `streamlit_app.py`。
2. 进入页面先输入管理员提供的访问密码。
3. 在自己电脑上双击 `编码密钥.cmd`，粘贴原始DeepSeek API Key后回车。输入时不显示字符属正常现象。
4. 复制工具输出的整行编码，包含 `D1.` 或 `K1.` 前缀。
5. 在看板“编码后的 DeepSeek 密钥”输入框粘贴，点击发送分析。程序在服务器内存中还原密钥，只作为API鉴权头使用。
6. 使用完可在侧栏“退出登录”，清除当前会话的登录状态、编码输入、数据和报告。

没有Windows启动器时，只需Python标准库，运行 `python key_codec.py` 即可编码。工具不联网、不写文件，也不回显原始密钥。

## 长度与含义

`sk-` 后面是偶数位小写十六进制字符时，工具将十六进制按字节压缩再做URL安全编码。例如35字符的测试密钥可变为25字符。前缀为D1.。

其他可打印英文密钥使用通用K1.编码，可能变长；任意随机密钥不能保证无损缩短。两种编码都去掉结尾等号，保留完整前缀即可准确解码。

编码不是加密。任何拿到编码结果与公开解码程序的人都可以恢复原始密钥；编码内容也应按密钥保管，不要上传GitHub、放入报告或发送给AI。固定共享访问密码写在程序中，公开源码不能用来保密这个口令。

本地ai_local.py中已有原始API_KEY时可以留空页面编码框，保留本地备用方式；输入了编码时优先使用它。云端没有ai_local.py也可以正常使用页面输入方式。
